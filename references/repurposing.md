# Repurposing One Piece Into Many

The goal is not five copies of one post. It is five different doors into the
same idea, each shaped for how people use that platform.

## 1. Build the idea inventory

Read the full source and fill this in before drafting anything:

| Field | Content |
|-------|---------|
| Core thesis | One sentence the whole piece argues |
| Supporting points | 3-7 points, each one line |
| Specifics | Numbers, names, examples, steps, quotes (note the source of each) |
| Best line | The most surprising or quotable sentence |
| Story | Any moment with tension, if the source has one |
| Audience | Who this helps, and what they want |
| CTA | What the reader should do next (read, subscribe, reply, try) |
| Gaps | Facts a post would need that the source does not provide |

For transcripts: strip filler, keep the speaker's distinctive phrasing,
attribute quotes to the right speaker, and never "improve" a quote while still
presenting it as verbatim.

For podcast notes with guests: get the guest's approval before quoting them in
promotional content if the user is unsure, and tag or credit them.

## 2. Angle matrix

| Platform | Best angle from the inventory | Shape |
|----------|-------------------------------|-------|
| X thread | The full argument, compressed | Hook post, 4-10 points, recap, CTA |
| LinkedIn | The lesson and the personal context behind it | Story or insight, one takeaway, question |
| Instagram carousel | The steps or framework | Promise, one idea per slide, summary, CTA |
| Short video | The single most surprising point or a quick demo | Hook, 3-5 beats, payoff, CTA |
| Threads / Bluesky | The best line or a sharp opinion | One post, optional reply chain |

If the source has only one strong point, do fewer platforms well rather than
stretching it thin. Say so.

## 3. Templates

### X thread

```
1/ [Hook - stands alone, under ~120 characters on the first line]
   [Optional second line that sets up the thread]

2/ [Point 1 - one idea, a specific]
3/ [Point 2]
...
N-1/ [Recap in one or two lines]
N/ [CTA. Link here or "link in the reply below".]
```
Checks: every post under the free-tier limit; no post depends on the next to
make sense; numbers sourced; links at the end.

### LinkedIn post

```
[Hook line 1]
[Hook line 2 - before the fold]

[Context: 1-3 short lines]

[Body: 3-5 short paragraphs or a short list]

[Takeaway: one line]

[Real question or CTA]

#HashtagOne #HashtagTwo
```
Checks: under 3,000 characters (aim 900-1,800); first two lines work alone;
no external link in the body if the user prefers reach (offer "link in
comments" as an option and say why).

### Instagram carousel

| Slide | Headline (on image) | Body (on image) | Visual note | Alt text |
|-------|--------------------|-----------------|-------------|----------|
| 1 | Promise in 6-10 words | - | Bold cover, high contrast | Describes the cover text and image |
| 2 | Immediate payoff | 15-40 words | ... | ... |
| ... | One idea per slide | ... | ... | ... |
| N-1 | Summary | ... | ... | ... |
| N | CTA (save, share, link in bio) | ... | ... | ... |

Caption: hook sentence before ~125 characters, 2-4 short paragraphs
expanding the slides, CTA, then up to 5 CamelCase hashtags. Keep 5-10 slides
unless the content truly needs more (maximum 20).

Alt text rules: describe the slide's text and any meaningful image in plain
language, under about 125 characters when possible; do not start with
"Image of".

### Short-video script

| Time | Spoken (voiceover / to camera) | On-screen text | Visual / B-roll |
|------|-------------------------------|----------------|-----------------|
| 0-3s | Hook | Hook in 3-7 words | Strong first frame, motion |
| 3-10s | Beat 1 | Key phrase | Cut / demo |
| 10-20s | Beat 2 | Key phrase | ... |
| 20-35s | Beat 3 / payoff | Key phrase | ... |
| End | CTA or loop line | CTA text | ... |

Add: target length, caption (with disclosure first if sponsored), cover/thumbnail
text, and a note that captions must be on. Spoken pace is roughly 2.5 words
per second; a 30-second script is about 70-80 words.

### Threads / Bluesky post

```
[One sharp sentence]
[One or two supporting lines]
[Optional: link card or "more in replies"]
```
Keep under 300 graphemes so the same text works on both. If it must be
longer, write a Threads version (500) and a Bluesky version (300).

## 4. Worked example (abbreviated)

Source: a founder's 1,500-word post about replacing a free trial with a
paid pilot.

Inventory: thesis "A paid pilot filtered for serious buyers"; specifics
from the source "trial-to-paid went from [source figure] to [source figure]";
best line "Free trials attracted tourists; paid pilots attracted buyers."

- X hook: "We killed our free trial. Fewer sign-ups, more customers. Here is
  what we changed and what broke. (1/7)"
- LinkedIn hook: "Our free trial was popular. That was the problem."
- Carousel cover: "Free trial vs paid pilot: what changed in 60 days"
- Video hook (spoken): "We started charging for our trial, and it worked."
- Bluesky: "Free trials attracted tourists. Paid pilots attracted buyers.
  Notes from switching:"

Every number in the final posts comes from the source; if the source did not
include one, the draft says `[ADD: trial-to-paid rate before/after]`.

## 5. Final checklist

- [ ] Each platform has a different shape, not a trimmed copy
- [ ] All limits respected with margin; counts shown
- [ ] Every claim traceable to the source or marked `[ADD]` / `[CHECK]`
- [ ] Alt text for every visual; captions for every video
- [ ] CamelCase hashtags within the platform cap
- [ ] Disclosure present if any sponsor, affiliate or ownership link
- [ ] Voice guide applied
